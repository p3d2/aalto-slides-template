## Component Preview

Component Preview demonstrates how a component works.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Component Preview includes one or more tabs, each of which displays the component implemented in a particular technology and possibly a source code snippet. The main purpose of Component Preview is to allow showcasing of the components on this very site.
