## Profile Card Collection

Responsive wrapper for displaying Profile Cards

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Profile Card Collection is a responsive wrapper for tiling a number of [Profile Card](/ds/modules/profile-card) modules next to each other.
