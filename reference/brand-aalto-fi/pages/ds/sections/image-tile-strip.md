## Image Tile Strip

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Image Tile Strip displays multiple [Image Tiles](/ds/modules/image-tile) in a horizontally scrollable container, allowing users to browse content efficiently.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Image Tile Strip when presenting multiple [Image Tiles](/ds/modules/image-tile) with dynamic content, where users can explore them at their own pace without needing to view every item. If all Image Tiles must be seen, consider using a [Image Tile Collection](/ds/sections/image-tile-collection) instead. Depending on the content type, alternatives like [Card Strip](/ds/sections/card-strip) or [Content Box Strip](/ds/sections/content-box-strip) might be more suitable.
