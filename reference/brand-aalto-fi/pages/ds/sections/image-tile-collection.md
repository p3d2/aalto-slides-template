## Image Tile Collection

Responsive wrapper for displaying Image Tiles

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Image Tile Collection is a responsive wrapper for tiling a number of [Image Tile](/ds/modules/image-tile) modules next to each other.
