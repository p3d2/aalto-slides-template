## Content Box Strip

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Content Box Strip displays multiple [Content Boxes](/ds/modules/content-box) in a horizontally scrollable container, allowing users to browse content efficiently.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Content Box Strip when presenting multiple [Content Boxes](/ds/modules/content-box) with dynamic content, where users can explore them at their own pace without needing to view every item. If all Content Boxes must be seen, consider using a [Content Box Collection](/ds/sections/content-box-collection) instead. Depending on the content type, alternatives like [Card Strip](/ds/sections/card-strip) or [Image Tile Strip](/ds/sections/image-tile-strip) might be more suitable.
