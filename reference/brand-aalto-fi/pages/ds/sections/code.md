## Code

Code section displays a piece of programming code.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Syntax highlighting makes it easier to read the code. There is support for a variety of different programming languages. The user may copy the code to the clipboard.

Under the hood, the Code sections simply wrap a [Code Preview](/ds/modules/code-preview) module in a responsive container.
