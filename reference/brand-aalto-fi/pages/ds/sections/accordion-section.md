## Accordion Section

Accordion Section is a responsive element that has an Accordion component nested inside.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Accordion Section wraps an [Accordion](/ds/components/accordion) module and an optional aside, providing a responsive container for an Accordion.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Accordion Section when you want a full-width responsive [Accordion](/ds/components/accordion) ready to be embedded on a page.

Accordion Section may also include an aside, for example, another component or module next to the Accordion.
