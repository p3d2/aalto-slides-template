## Modal

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Modal is a temporary overlay or pop-up window that appears on top of the main content in a view. Modals are commonly used to display important information, messages, or interactive content that requires user attention or input without navigating away from the current context. They typically contain a primary action, such as confirming a decision, and possibly additional alternative actions.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Modals should be used sparingly and only for important actions or information that require immediate user attention. Keep modals concise and focused, avoiding unnecessary clutter or excessive content. If the content seems to be too extensive for a modal, you should probably consider using a separate page instead.
