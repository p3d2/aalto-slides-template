## Text and image

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Text and Image enables the enhancement of a text section with a relevant image. Additionally, you can include an optional call-to-action button or a set of links.

###### Usage

Consider using Text and Image as an alternative to [Liftup Collection](/ds/sections/liftup-collection) / [Card Collection](/ds/sections/card-collection) to prevent visual monotony on a page. For a more dynamic layout, combine this section with other elements like plain [Text Chapters](/ds/sections/text-chapter) and the aforementioned collections.
