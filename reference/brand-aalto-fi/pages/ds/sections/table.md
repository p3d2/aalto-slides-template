## Table

Tables present data in a more visual format.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Tables provide a simple way to organise information. It presents data in columns and rows and makes large amounts of information easier for the user to scan and compare. There are different building blocks for different data needs.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Tables are used for presenting data in a more visual and structured way. They are not used for simple, non-tabular data, or for emphasizing certain sections of data.
