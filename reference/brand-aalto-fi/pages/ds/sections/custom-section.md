## Custom section

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Custom Section is a special tinkering tool which may be used for composing bespoke sections either based on the existing design system modules or completely custom-made modules only available in a channel's code base.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Custom Section is meant for advanced users who need to implement elements not currently available as part of the standard design system library. If your project necessitates creating such custom elements, you might want to contact the design system team and discuss whether the new section should be included in the main library, or if there already is a solution available.
