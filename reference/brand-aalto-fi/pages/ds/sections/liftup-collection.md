## Liftup Collection

Responsive wrapper for displaying Liftups

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Liftup Collection is a responsive wrapper for tiling a number of [Liftup](/ds/modules/liftup) modules next to each other.

<!-- slice: page_section_element -->
