## Chip

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Chip is a compact component used to display short pieces of text, such as filters, selections, or keywords. A Chip can be removed or dismissed by clicking it.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Chip as a compact visual to represent user-selected values or active filters that can be dismissed. The label should be brief to maintain clarity and visual balance.

Chips typically appear dynamically as a group inside a [Chip Group](/ds/components/chip-group) component. Chip is intended for interactive use where items need to be removed individually. Unlike [Tags](/ds/components/tag), chips don't have links, and users can close them. Chips trigger actions but do not transfer the user anywhere.
