## Image link

Image link is a type of hyperlink where an image is displayed instead of text.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

When a user clicks or taps on the image, the linked resource will open either in the same browser window or a new one.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Image link is used in various places, such as in the main navigation, photo galleries, articles, product listings, and social media posts. Due to accessibility reasons, Image links should only be used scarcely and always have a descriptive alt text defined.
