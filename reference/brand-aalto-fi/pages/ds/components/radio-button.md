## Radio Button

Radio Button allows users to select only one option.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Radio Buttons allow choosing a single option out of multiple side-by-side options. When one option is selected, the other ones will become deselected. Using a single Radio Button without a [Radio Group](/ds/components/radio-group) is therefore only ever necessary for library developers.
