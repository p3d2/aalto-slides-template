## Text Area

Text Area allows entering multiple lines of text.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Text Area is able to grow vertically while writing multiple lines of text. Besides the actual input area, Text Area may contain a label and a hint text. When there is no input written in Text Area, a dimmed placeholder text is shown instead.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Text Area is used when the expected answer is more than a single line of text. It is mostly used in open-ended questions in forms.

Text Area is not used for answers shorter than a single line of text, such as a name or a phone number. For single-line inputs, [Text Input](/ds/components/text-input) is used instead.

When using a Text Area, it is important to carefully consider the copywriting of the hint and placeholder texts to ensure the user understands the intended meaning.
