## Button

Buttons trigger actions or events.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Buttons help users start actions and submit information. Different variants of buttons help create a hierarchy within pages and services.

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

###### Examples

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

###### Default button

Default button communicates a neutral action, which is safe for the user, and something they would likely choose to click.

**page_section_element.component_id:** components/button--default

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

###### Primary button

Primary button is used to indicate the main action on the screen. Primary actions are typically mandatory or otherwise important. Only one primary button can be used per section or view.

**page_section_element.component_id:** components/button--primary

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

###### Icon button

Icon button communicates the following interaction through a symbol. Multiple buttons of this kind can be displayed together using a [Button group](/ds/components/button-group).

**page_section_element.component_id:** components/button--icon

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

###### Overlay button

Overlay button is intended to be placed on top of an image, video or similar busy background. Multiple buttons of this kind can be displayed together using a [Button group](/ds/components/button-group).

**page_section_element.component_id:** components/button--overlay

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

###### Disabled button

Any button variant can be disabled, indicating the user can not interact with the button right now. This example shows the Default variant in the disabled state.

**page_section_element.component_id:** components/button--default-disabled

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

###### Button with icon

Button can have an icon either on the left or right side of the label text.

**page_section_element.component_id:** components/button--icon-on-left

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Buttons are used throughout the UI in places like dialogues, cards, modal windows, and forms. They are also used in actions like submit, cancel, edit, save, and open. Buttons should not be used as links to other pages - there's the [Link component](/ds/components/link) for that purpose.
