## Radio Group

Radio Group presents a set of options, of which only one can be selected at a time.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Radio Group allows choosing a single option out of multiple side-by-side options. Radio Group shows all the options simultaneously in a list format and makes it easy to scan and compare them.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Radio Group is used when a single option can be chosen from a list of at least two options. Selecting one option will deselect another. Radio Groups are used for example in forms, tables, lists, and filters. Radio Group is not used when multiple options can be chosen. Checkbox or Dropdown are used instead. Furthermore, in case there are four or more options, a [Dropdown](/ds/components/dropdown) is typically a better choice.
