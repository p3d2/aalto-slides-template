## Slider

Sliders allow users to select values within a specified range.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Slider consists of a track, which represents the range, and one or more handles that can be dragged along the track to indicate the selected value. The corresponding values are displayed below the track.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Sliders are best suited for scenarios where the user needs to input a value within a defined range, such as adjusting a setting or parameter. They provide an intuitive way for users to control and fine-tune values, in many cases offering a more visual and interactive experience compared to other possible input methods such as Text Input or a Dropdown menu. However, it's important to consider the context: if the range of values is exceptionally large or requires high precision, a Slider may not be the most efficient choice.
