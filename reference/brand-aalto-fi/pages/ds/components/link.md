## Link

Link transfers the user from one page to another.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Links guide users to get further information from another page. The information behind a link is usually related to the content on the current page.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Links offer a way to move from one page to another and gather more information. Links do not guide users to take action, and no necessary actions are hidden behind them. For call-to-action elements use [Buttons](/ds/components/button).
