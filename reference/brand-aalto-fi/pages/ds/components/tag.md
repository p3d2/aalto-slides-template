## Tag

Tags are interactive information labels.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Tags are labels that categorise items using keywords. They represent attributes that determine the item they appear with as part of a certain category or categories. Depending on the type of content, Tags can be static or interactive.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Tag to display labels that describe or categorise content. As Tags are typically not user-removable, for dynamic or dismissible filters the [Chip](/ds/components/chip) component is usually a better choice. For temporary status or notification messages, use [Badge](/ds/components/badge). Multiple Tags can be displayed together using the [Tag Group](/ds/components/tag-group) component.
