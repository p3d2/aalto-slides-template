## Button group

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Button Group is a wrapper component used to display a horizontal set of icon-based [Buttons](/ds/components/button). It supports only the *icon* and *overlay* button types.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Button Group to present a collection of compact, icon-only actions. It is typically used for social media links, toolbar actions, or other grouped functions in compact layouts. Do not include buttons with text labels, only icon or overlay buttons are supported.
