## Switch

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Switch is a UI component for toggling between two states. Switch provides a visual indicator of the current state and allow users to change it with a simple interaction, tapping or clicking. The component also includes a label, providing additional context or description for the options presented.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Switches for binary options where users need to choose between two mutually exclusive states like on/off, enabled/disabled, or active/inactive. Ensure Switches are clearly labeled to indicate what each state represents.

Differentiate between Switches and [Checkboxes](/ds/components/checkbox): Switches are ideal for toggling between two distinct states, while Checkboxes are suitable for selecting one or more options from a list of choices. Toggling a Switch typically triggers an action instantly upon interaction, while a checkbox usually requires confirmation.
