## Mega link

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Mega Link navigates the user to another page, similar to a standard [Link](/ds/components/link) but with greater visual emphasis and space for additional information.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Mega Links in contexts where additional information beyond a standard link label is needed. For example, they are useful for highlighting key navigation options, featuring related content, or providing brief descriptions alongside the link.
