## List

List is a vertical group of content

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

List displays vertically stacked items in a single column. It supports multiple levels of hierarchy and can include both static text and links.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use List to organise related content such as navigation links, grouped references, or supporting details. Lists can be flat or nested, with indentation indicating hierarchy. Avoid excessive nesting to preserve clarity.

List is best suited for relatively simple content that fits within a single column. For more structured or detailed information, consider using a [Table](/ds/sections/table) or [Directory](/ds/sections/directory). For interactive or collapsible navigation, see [Navigation accordion](/ds/modules/navigation-accordion).
