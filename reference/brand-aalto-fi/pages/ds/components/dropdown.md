## Dropdown

Dropdown shows a list of selectable options or actions to choose from.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Dropdown contains a dropdown button and a dropdown menu. A dropdown menu is a list of options that appears upon clicking the field.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Dropdowns are used mostly in forms, modals, and filters. If there are fewer than three options to choose from, a [Radio Group](/ds/components/radio-group) or a [Checkbox Group](/ds/components/checkbox-group) should be preferred whenever there is enough space available in the user interface.

Dropdown is not meant for complex or long information and the options need to be as compact as possible. Be mindful of the number of options.
