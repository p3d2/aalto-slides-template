###### Figma design library

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Aalto Design system library consists of components, modules, sections, and design tokens that are required to build Aalto’s digital products. To start using Aalto Design system libraries in your Figma project, you will need access to the design system library project in Aalto’s Figma. To obtain access, kindly reach out to the Design system team.

If you find that the current design is missing elements or is not usable with your platform, we encourage you to reach out to the Design system team to discuss the possibilities for expanding the shared libraries.

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

###### Using Figma design library

1. Access the design library: Open your Figma project and locate the design library file (.fig file) that contains the desired design components and styles.

2. Add the design library: Go to the main menu and select "File" > "Add Library to Figma." Choose the design library file from your local storage

3. Enable the design library: Once added, enable the design library by selecting "Plugins" > "Manage Libraries" from the main menu. Enable the library by toggling the switch next to its name.

4. With the design library enabled, you can start using its components in your Figma project. Access the components panel (or use the shortcut "Cmd+/") and browse through the library to find the desired components. Drag and drop components onto your canvas.

5. The design library also includes predefined text styles, colour palettes, and other design elements. To apply styles from the library, select the desired text or shape, and choose the appropriate style from the styles panel or the right-click context menu.

###### Icons

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Aalto uses an icon font that can be easily inserted and styled using font ligatures. You need to download the Aalto icon font to edit icon parameters like colors or sizing. Download the font and install it on your computer. Once the font is installed, you can insert icons into your design with the icon ligature names.

###### Using icons

1. Download the icon files using the link above
2. Extract the .zip archive on your local computer (typically just double click it)
3. In the folder, locate the font file **/fonts/aalto-icons.ttf**
4. Install the font into your local computer
5. Close Figma and restart
6. Select **aalto-icons** from the fonts list in the Text panel
7. Add an icon by typing the corresponding ligature name, for example *icon-quotation-marks
