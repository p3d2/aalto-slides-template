## Icons

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

The Aalto design system offers a fundamental collection of icons that are well-suited for any digital user interface and specifically designed to work together with the other Aalto design elements, such as typography and colour. Consistently using these recognisable icons across various digital channels helps create a seamless and intuitive user experience that aligns with the brand.

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: tokens_section -->

### Icon system

The icons are provided as a font file, which is the most convenient way to use them on most platforms. However, they can also be used as vector graphics files if necessary.

You can download the icons on the [For designers page](/ds/for-designers).

Icons are named by describing what can be seen to make them use-case agnostic. There are a few exceptions, like *play* or *copy* that would be unnecessarily hard to find when named otherwise.

Icon name can include three parts:
- Token type, in this case icon
- Form, that describes the dominant shape of the icon
- Descriptor, that works as a cue for the visual presentation
For example the general check mark icon is named *icon-check-mark*. The icon where a check mark is enclosed in a circle is *icon-circle-check-mark*.
