## Grids & spacing

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Organising visual content in a grid is essential to establishing a sense of structure and organisation for any layout. While the final decisions always remain in the hands of the designer, the Aalto design system provides an array of tools and assets that make it easy to create consistent, responsive layouts for any digital medium. In addition to enhancing the aesthetic quality of your design, adhering to set layout rules helps ensure compliance with accessibility standards and fundamental principles of good user interface design.

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: tokens_section -->

### Dimensions

The foundation of the Aalto design system grid is the 1 rem / 16 px unit. Ideally, most content should be arranged using a 1rem x 1rem grid, including visual item sizes and negative space. However, in some instances, smaller distances may be necessary and the Aalto design system thus provides a set of tokens to accommodate those needs as well.

### Breakpoints

Breakpoints enable the adaptation of digital content display in response to a user's device viewport size, allowing for adjustments for example in layout, typography, or the visibility of individual visual elements. The Breakpoint design tokens in the Aalto design system offer an efficient means of delivering responsive design across diverse screen sizes and device types.

### Layout grid

The Aalto design system uses a 12-column layout grid to help structure and organise content in a responsive way across various screen sizes. From tablets and up, all breakpoints follow this standard grid. On smaller mobile phone screens, a 2-column layout is utilized instead.

While it's possible for designers to place elements outside of the grid columns, it is recommended to align content in relation to the columns for consistency and harmony between different content modules.

### Aspect ratio

To maintain visual consistency, it's recommended to present visual content, such as photography, illustrations, or video, in one of the standard aspect ratios. This not only improves the overall coherence of the design but also ensures that the same content can be easily repurposed for use across different channels without having to adjust it individually for various platforms and devices.
