## Date Input

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Date Input combines a text input field with a [Date Picker](/ds/modules/date-picker), allowing users to either type a date manually or select one from a calendar. The Date Picker pops up when the input field is selected, providing an alternative, more visual way of choosing a date.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Date Input is typically used as a [Form](/ds/sections/form) element. It provides the flexibility of both manual entry for users familiar with the format and a calendar view for those who prefer selecting dates visually. However, Date Input is less suited for mobile devices, as the on-screen keyboard can take up significant space and obstruct the calendar when the text field is focused. In such cases, it's better to use a [Date Picker Modal](/ds/sections/date-picker-modal) to provide a more optimised, full-screen date selection experience.
