## Directory Block

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

The Directory Block lists a structured collection of [Info Items](/ds/modules/info-item), each typically with a title, body, and additional information. The items may be organised in pairs consisting of the main info and additional details.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Directory Blocks are typically not used as such, but rather as parts of a [Directory](/ds/sections/directory) section. Unless you are building a custom section, you will most probably want to use a Directory instead.
