## Navigation Accordion

Navigation Accordion organises navigation hierarchy.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Navigation Accordion has layers of navigation information. Besides the main sections, users can navigate through subsections for more specific information. Navigation Accordion saves space on layout and enables more information in smaller spaces.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Navigation accordions are suitable for situations where the main navigation consists of two levels and there are two or more subsections. As you can see on the current website, navigation accordions can be employed as part of [Side Navigation](/ds/modules/side-navigation) (on desktop) or [Top Navigation](/ds/sections/top-navigation) (on mobile).
