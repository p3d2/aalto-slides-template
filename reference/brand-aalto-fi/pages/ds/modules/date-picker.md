## Date Picker

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Date Picker enables users to choose a single date or a date range through an interactive calendar interface. It displays the current month with selectable days, and users can navigate between months using arrow buttons. Selected dates are highlighted to provide visual feedback.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

The Date Picker is used anywhere date input is required. It simplifies date selection, reducing user error compared to manual input. While an individual Date Picker can be embedded in any kind of user interface element, see also [Date Input](/ds/modules/date-input) and [Date Picker Modal](/ds/sections/date-picker-modal) for alternatives.
