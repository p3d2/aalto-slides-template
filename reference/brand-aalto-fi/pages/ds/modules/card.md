## Card

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Card is a clickable container used to highlight key content areas. It typically includes a title, optional image, short description, and a visual link indicator.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Card is a visual convention of grouping and displaying information together, making it visually pleasing and easy to scan. Use cards for a single topic, do not mix information in them.

Use Card when the user is expected to navigate to another page. The entire module is clickable, supporting a seamless and intuitive interaction. Cards are typically used in sets to surface relevant destinations or entry points on a page. See [Card Collection](/ds/sections/card-collection) and [Card Strip](/ds/sections/card-strip) for layout options.

If the action is not navigation, but something else such as downloading a file, use the [Liftup](/ds/modules/liftup) module instead. If no interaction is needed, consider using the [Content Box](/ds/modules/content-box) or [Image Tile](/ds/modules/image-tile) depending on the content type. 

Cards are intended for concise content. If you need to present more detailed information, consider using e.g. a [Text and Image](/ds/sections/text-and-image) section instead.
