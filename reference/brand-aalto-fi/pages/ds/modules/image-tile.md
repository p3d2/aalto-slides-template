## Image tile

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

An Image Tile presents a visual element with an optional caption. It is non-interactive and can display either an image or a video.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Use Image Tiles to showcase visual media in a grid or gallery format, especially when no interaction is required, typically arranged using an [Image Tile Collection](/ds/sections/image-tile-collection) or [Image Tile Strip](/ds/sections/image-tile-strip). It supports both static imagery and embedded video, making it well suited for media-rich layouts.

Image Tile highlights visual content. If the text accompanying the media is critical, consider using a [Content Box](/ds/modules/content-box). If the media needs to link to another page or action, use [Card](/ds/modules/card) or [Liftup](/ds/modules/liftup) instead.
