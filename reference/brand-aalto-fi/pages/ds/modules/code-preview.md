## Code Preview

Code Preview displays a block of programming code.

<!-- layout: theme=black -->

<!-- slice: page_section_element -->

Code Preview displays code within a dark background container. Different programming languages are supported, allowing for language-specific syntax highlighting. Besides viewing the code, the user may copy it to the clipboard.

###### Usage

<!-- layout: alignment=left, theme=neutral -->

<!-- slice: page_section_element -->

Code Preview can be used whenever there is a need to display programming code, for example when writing instructions for programmers or documenting a particular implementation. Note that there is also [Code](/ds/sections/code) section, which might be more suitable for building full pages.
